> 前四章读完后,用这些实验把知识变成手感。全部可直接在你的 yolo-web 项目上做。

## 实验 1:解剖一次预测(验证 02 章)

新建 `exp1.py` 放在 yolo-web 目录,运行:

```python
from ultralytics import YOLO
import ultralytics.assets as A, os, cv2

m = YOLO("yolo11n.pt")
img = cv2.imread(os.path.join(os.path.dirname(A.__file__), "bus.jpg"))

r = m.predict(img, conf=0.4, verbose=False)[0]
print("框数量:", len(r.boxes))
print("坐标 xyxy:\n", r.boxes.xyxy)
print("置信度:", r.boxes.conf)
print("速度(ms):", r.speed)   # 观察 inference 占比
```

**任务**:把 `conf` 改成 0.1 和 0.9,记录框数量变化;把 `iou` 改成 0.2,观察近距离物体重叠框是否被误删。

## 实验 3:解释你的训练曲线(验证 03/04 章)

训练完一次后,用 Excel 或文本编辑器打开 `models/run/results.csv`:

- 找到 `train/box_loss` 列,看它是否持续下降
- 找到 `metrics/mAP50(B)` 列,确认 best.pt 对应的轮数
- 打开 `confusion_matrix.png`:你的类别是否被认错成背景(说明标注框不准或数据太少)

## 实验 4:改一个超参数,对比训练(验证 03 章)

在 `app.py` 的 `run_training()` 里改(每次只改一项):

| 改动 | 预期效果 |
|---|---|
| `lr0=0.001`(默认 0.01) | 收敛更慢更稳 |
| `freeze=8` | 前 8 层不训练,小数据集可能更抗过拟合 |
| `augment=False` | 关闭 mosaic 增强,小数据集会更差 |
| `patience=10` | mAP 连续 10 轮不涨就早停,省时间 |

## 实验 6(进阶):绕过高层 API 自己写推理

完全用底层接口复刻 predict,理解 02 章的每一环:

```python
import torch, cv2
from ultralytics.nn.autobackend import AutoBackend
from ultralytics.data.augment import LetterBox
from ultralytics.utils import nms, ops    # 8.4 版 NMS 在 ultralytics.utils.nms

device = torch.device("cpu")
model = AutoBackend(model="yolo11n.pt", device=device)  # 注意参数名是 model

img = cv2.imread("某张图.jpg")
lb = LetterBox(640)                        # ① 预处理
im = lb(image=img)
t = torch.from_numpy(im).permute(2,0,1).unsqueeze(0).float()/255

preds = model(t, augment=False)            # ② 前向 → (1, 84, 8400)
raw = preds[0] if isinstance(preds,(list,tuple)) else preds
out = nms.non_max_suppression(raw, conf_thres=0.4, iou_thres=0.7)[0]  # ③ NMS
ops.scale_boxes(t.shape[2:], out[:, :4], img.shape)                    # ④ 坐标还原
print(out)   # 每行 [x1,y1,x2,y2,conf,cls],和 results.boxes 一致 → 你已经懂了整个推理管线
```
