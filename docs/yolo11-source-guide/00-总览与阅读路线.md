## 为什么不逐行注释官方源码

ultralytics 工程约 10 万行,且持续更新。逐行注释既看不完也会很快过时。
学习工业级开源项目的正确方法是:**抓住 20% 的核心文件,理解数据如何流过它们**。
本导读就是把这条主线抽出来,配上中文详解。

## 一条命令背后的调用链(务必先记住这个)

```python
from ultralytics import YOLO
model = YOLO("yolo11n.pt")          # 你在 app.py 里写的两行
results = model.predict(frame)
```

实际发生的事:

```
YOLO("yolo11n.pt")
  └→ UL/engine/model.py   YOLO.__init__ → _load()
       从 .pt 里读出权重点积 + 网络结构配置,重建 DetectionModel

model.predict(frame)
  └→ UL/engine/model.py   YOLO.predict()
       └→ UL/engine/predictor.py  BasePredictor()
            1. 预处理:letterbox 填充缩放 / 归一化 / 转 tensor
            2. 前向推理:UL/nn/autobackend.py  AutoBackend.forward()
                 → UL/nn/tasks.py  DetectionModel.forward()
                      内部走 parse_model 搭出的 Backbone→Neck→Head
            3. 后处理:UL/utils/ops.py  non_max_suppression()
                 去掉重叠框,只留最好的
            4. 打包:UL/engine/results.py  Results 对象(boxes/masks/...)
                 results[0].plot() 就是画好框的那张图
```

## 训练的调用链

```python
model.train(data="data.yaml", epochs=30)   # 你在 app.py 里写的
```

```
YOLO.train()
  └→ UL/engine/model.py  YOLO.train()
       └→ UL/models/yolo/detect/train.py  DetectionTrainer(BaseTrainer)
            └→ UL/engine/trainer.py  BaseTrainer.train() → _do_train()
                 每个 epoch 循环:
                   取一批图 → 模型前向 → UL/utils/loss.py  v8DetectionLoss
                   算损失 → 反向传播 → 更新权重
                 每个 epoch 结束:跑验证 → 触发回调(你的进度条就是这么来的)
```

## 目录地图(UL/ 下哪些值得读,哪些可以跳过)

```
UL/
├── engine/          ★★★ 必读:框架层
│   ├── model.py        YOLO 门面类:predict/train/val 都从这里进
│   ├── trainer.py      ★ 训练主循环 _do_train()
│   ├── predictor.py    推理主循环
│   ├── results.py      Results:检测结果的对象表示
│   └── validator.py    验证/mAP 计算
├── nn/              ★★★ 必读:网络定义
│   ├── tasks.py        ★ parse_model():把 yaml 变成 PyTorch 模型
│   ├── autobackend.py  推理后端封装(支持 onnx/tensorrt 等)
│   └── modules/        ★ 积木块:Conv/C3k2/SPPF/Detect 等
├── models/yolo/     ★★ 任务适配层(detect 检测 / segment 分割 / pose 姿态…)
│   ├── detect/train.py     DetectionTrainer(232行,适合第一个精读)
│   ├── detect/val.py       DetectionValidator(mAP 计算)
│   └── segment/            ★ 分割训练/验证:你的 app.py 用的就是这条线
│                           (SegmentationTrainer 额外算 mask_loss)
├── utils/           ★★ 工具箱
│   ├── loss.py         ★ v8DetectionLoss(损失函数核心)
│   ├── ops.py          NMS、坐标变换
│   └── tal.py          TaskAlignedAssigner(正负样本分配)
├── cfg/             ★ 配置:模型 yaml + 默认超参 default.yaml
├── data/            数据加载、增强(mosaic 等)
└── solutions/  trackers/  hub/   ← 应用层,入门阶段跳过
```

## 读源码的三个技巧

1. **跟着数据走,不要跟着代码走**:时刻问"现在图片是什么形状?经过这层变成什么?"
2. **善用断点**:在 app.py 的 `draw_detections()` 里 `print(results[0].boxes)` 亲手摸一遍数据
3. **改一行跑一次**:把某个模块换掉/删掉看会发生什么,比读十遍注释记得牢
