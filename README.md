# YOLO 平板-电脑协同学习平台(分割测量版)

电脑(CPU)运行 YOLO 分割推理与几何测量服务,平板连同一 WiFi,用浏览器访问即可。
适用于工业缺陷检测学习:缺陷分类 + 面积 / 内外径 / 焊缝宽度测量。

## 启动

```bash
cd yolo-web
python app.py
```

## 平板访问

平板浏览器打开:**http://192.168.2.57:8000**
(具体 IP 以 `ipconfig` 查询结果为准;若 Windows 防火墙拦截,首次运行时选择"允许访问")

## 功能

- 📸 平板拍照/选图上传 → 电脑 yolo11n-seg 分割推理 → 返回掩码标注图
  + 测量表:**面积、外径、内径、焊缝宽度**(支持"1像素=多少mm"标定)
- ✏️ 标注页:矩形/多边形两种标注模式,已保存标注自动回显
- 🏋️ 一键训练:yolo11n-seg 迁移学习,平板实时看进度,训完自动换模型
- 🎥 电脑摄像头实时分割流(MJPEG),平板实时观看
- 📚 页面内置 YOLO 知识讲解和小实验建议

## 技术栈

Flask + ultralytics(yolo11n-seg) + OpenCV,CPU 推理约 1s/张。
测量原理:掩码外轮廓→面积/外径,内部孔洞→内径,细长掩码短边→焊缝宽度。

## 常改的参数(app.py)

- `conf=0.4` — 置信度阈值,调低识别更多但误报多
- `YOLO("yolo11n-seg.pt")` — 可换 yolo11s-seg.pt 更准但更慢
- `port=8000` — 服务端口
- `mm_per_px`(首页输入框)— 像素-毫米标定系数
